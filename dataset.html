Pipeline and Grid Cyber-Physical Incident Panel (v1.0)

The Pipeline and Grid Cyber-Physical Incident Panel (v1.0) is a unified research dataset that harmonizes PHMSA pipeline incident records and DOE OE-417 electric disturbance reports into a single, structured panel suitable for cyber-physical infrastructure analysis. The project integrates multiple federal data sources, standardizes schema and terminology, and applies a control-system and telecommunications involvement classification to each record using a structured YAML taxonomy.

The dataset includes 12,935 total records, consisting of 9,654 PHMSA incidents and 3,281 OE-417 disturbance reports, covering the period beginning in 2010. Outputs include a harmonized CSV file, a provenance JSON file, and detailed fetch and join logs for reproducibility and auditability.

ONG‑OT Vulnerability Prioritization Dataset

The ONG‑OT Vulnerability Prioritization Dataset is a domain‑expert, reproducible dataset integrating CISA ICS Advisories, CISA KEV, FIRST.org EPSS, CISA Vulnrichment, and MITRE ATT&CK for ICS.
